# Lace Animals — attribution (test-only, source not yet in hand)

- **What it is**: the Kemp & Tenenbaum animal-features table
  (50 animals x 85 binary features from Osherson et al.), distributed
  as `lace.examples` Animals by the Lace project (the maintained
  CrossCat implementation) — the head-to-head baseline in issue #22.
- **Status**: not bundled. The Lace code/data distribution point was
  not located from this environment (the probcomp GitHub org hosts
  CrossCat and BayesDB but no Lace repository). When the
  `lace.examples` data is in hand, this entry becomes a normal
  bundled/test-only dataset with its license recorded from the source.
