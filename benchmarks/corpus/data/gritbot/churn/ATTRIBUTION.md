# Telecommunications churn — attribution (test-only, source unresolved)

- **What GritBot used**: simulated telecommunications churn data formerly
  distributed by the MLC++ site at SGI: 5,000 cases (data + test),
  21 attributes. RuleQuest's sample results report two flagged cases,
  including a voice-mail plan holder with zero voice-mail messages.
  Source: https://rulequest.com/gritbot-examples.html
- **Status**: the MLC++ distribution point no longer exists. The same
  dataset circulates as the churn training/test data in the R package
  C50 (3,333 + 1,667 = 5,000 cases), but its redistribution terms have
  not been verified for this use, so nothing is bundled or fetched by
  the harness yet. Registry entry records the expectations from
  RuleQuest's published output.
